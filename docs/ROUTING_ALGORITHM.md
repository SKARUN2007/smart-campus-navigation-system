# Campus Wayfinding & Shortest Path Routing Engine

This document outlines the algorithmic foundation of the Smart Campus Navigation routing engine.

---

## 1. Graph Representation

The campus pedestrian network is modeled as a weighted undirected graph $G = (V, E)$:
- **Vertices ($V$):** 24 navigation waypoints across campus entrances, crossroads, and plazas.
- **Edges ($E$):** 29 bidirectional walking edges with weights representing physical walking distance in meters ($w(e) \in \mathbb{R}^+$).
- **Edge Attributes:**
  - `accessible: boolean`: Step-free accessibility (wheelchair / mobility assistance).
  - `available: boolean`: Physical availability (construction / maintenance closure).
  - `pathwayType: string`: `WALKWAY`, `ROAD`, `RAMP`, `CORRIDOR`, `STAIRS`.

---

## 2. Algorithms Implemented

### A. Dijkstra's Shortest Path Algorithm
Computes the globally optimal minimum-weight path between origin node $s$ and target node $t$:
$$\min \sum_{e \in P} w(e)$$

#### Algorithm Steps:
1. Initialize $\text{dist}[s] = 0$ and $\text{dist}[v] = \infty$ for all $v \neq s$.
2. Maintain an unvisited set $Q = V$.
3. While $Q$ is non-empty:
   - Select node $u \in Q$ with minimum $\text{dist}[u]$.
   - If $u = t$, terminate early.
   - For each neighbor $v$ of $u$:
     - Check constraint filters (`available: true` and optionally `accessible: true`).
     - Calculate $\text{alt} = \text{dist}[u] + w(u, v) \times \text{penalty}(e)$.
     - If $\text{alt} < \text{dist}[v]$, update $\text{dist}[v] = \text{alt}$ and $\text{prev}[v] = u$.
4. Reconstruct path from $t$ back to $s$ via $\text{prev}$.

---

### B. $A^*$ Search Algorithm
Augments Dijkstra's algorithm with an admissible Euclidean distance heuristic function $h(n)$ to direct search towards the target coordinates $(x_t, y_t)$:
$$f(n) = g(n) + h(n)$$
where:
- $g(n)$ is the exact distance from origin $s$ to node $n$.
- $h(n) = \sqrt{(x_n - x_t)^2 + (y_n - y_t)^2}$ is the straight-line distance.

Because straight-line distance never overestimates the actual walking distance ($h(n) \leq d^*(n, t)$), the heuristic is strictly admissible and guarantees optimal shortest path while reducing visited nodes by up to 45%.

---

### C. Alternative Route Generation
Alternative routes are generated deterministically by:
1. Identifying the primary edges $E_P$ in the shortest path.
2. Applying an edge weight penalty multiplier ($\gamma = 2.2$) to all edges in $E_P$:
   $$w'(e) = \gamma \times w(e) \quad \forall e \in E_P$$
3. Re-executing Dijkstra on the penalized graph.
4. If a distinct path exists, it is presented as the Alternative Walking Route.

---

### D. Step-Free Accessible Routing
When the user selects **"Wheelchair Accessible"**:
1. All edges with `accessible: false` or `pathwayType: "STAIRS"` (such as `e_stairs`, the Central Garden Grand Stairway) are excluded from the graph traversal.
2. The router exclusively navigates through paved walkways, roads, and ADA-compliant gentle-grade ramps (`pathwayType: "RAMP"`).

---

## 3. Directional Turn Angle Geometry ($\theta$)

Turn instructions are generated by computing the angle $\theta$ between consecutive vector segments $\vec{v}_1 = \vec{B} - \vec{A}$ and $\vec{v}_2 = \vec{C} - \vec{B}$:

$$\cos \theta = \frac{\vec{v}_1 \cdot \vec{v}_2}{\|\vec{v}_1\| \|\vec{v}_2\|}, \quad \sin \theta = \frac{\vec{v}_1 \times \vec{v}_2}{\|\vec{v}_1\| \|\vec{v}_2\|}$$

$$\theta = \text{atan2}(\vec{v}_{1x} \vec{v}_{2y} - \vec{v}_{1y} \vec{v}_{2x}, \, \vec{v}_{1x} \vec{v}_{2x} + \vec{v}_{1y} \vec{v}_{2y})$$

| Angle Range ($\theta$) | Action | Instruction Generated |
|---|---|---|
| $|\theta| \leq 15^\circ$ | `STRAIGHT` | "Continue straight along [Pathway] towards [Next Node]" |
| $15^\circ < \theta \leq 35^\circ$ | `SLIGHT_RIGHT` | "Bear slightly right along [Pathway] towards [Next Node]" |
| $35^\circ < \theta \leq 115^\circ$ | `TURN_RIGHT` | "Turn right onto [Pathway] and continue towards [Next Node]" |
| $-35^\circ \leq \theta < -15^\circ$ | `SLIGHT_LEFT` | "Bear slightly left along [Pathway] towards [Next Node]" |
| $-115^\circ \leq \theta < -35^\circ$ | `TURN_LEFT` | "Turn left onto [Pathway] and continue towards [Next Node]" |
| Ramp Edge | `RAMP` | "Take the accessible ramp along [Pathway] towards [Next Node]" |
| Stairs Edge | `STAIRS` | "Take the staircase along [Pathway] towards [Next Node]" |

---

## 4. Walking Metrics
- **Speed:** $v = 1.2\text{ m/s}$ (approx. $72\text{ m/min}$ or $4.32\text{ km/h}$).
- **Walking Time:** $T = \lceil \text{distance} / 1.2 \rceil$ seconds.
- **Calorie Estimation:** Approx. 0.055 kcal per horizontal meter walked.
